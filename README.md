# Stödmedlem KBK F2017

Stödmedlemssida för Kungsladugårds BK F2017. Välj belopp och vem du hejar på,
så får du en färdig Swish-länk (mobil) eller QR-kod (dator) med lagets nummer,
belopp och meddelande ifyllt.

Live: https://8bitcat.github.io/kbk-f2017/

- `index.html` – hela sidan (spelarlistan ligger överst i skriptet, `SPELARE`)
- `bilder/` – klubbmärke, lagfoto och cupfoton (nedskalade till 1800 px)
